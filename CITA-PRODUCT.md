# Çita MVP

Implement end-to-end in this isolated clone of CoachReachAI. You are implementation owner. Read AGENTS.md and existing Next.js version docs before modifying. Preserve existing coach PWA and 1:1 students and data. Build iOS + Android student app with Expo React Native, existing Next.js coach/admin web and Supabase auth/data/RLS. Use migrations, no live DB writes or deployment. Keep secrets server side; use test adapters when credentials unavailable, documented and never pretend production verification. Work in milestones, track completion in CITA-STATUS.md and commit to local feature branch only. No pushes. Run verification and report blockers.

## Product
Turkish YKS (TYT/AYT/YDT as appropriate) and LGS. App and mascot both Çita, sporty warm but direct, navy and warm orange design direction, chat first. Native tabs Koç, Program, Gelişim, Bire Bir. Mascot-led anonymous short onboarding asks exam/track, goal, baseline or weak subjects, availability. Preview full seven-day personalized plan, allow changes, then optional signup to save and start free. Existing accounts can log in immediately. No coach code required for B2C; retain legacy linking. Program tasks, timers, study history and daily chat use actual records. Weekly target, streak (planned rest days excluded), and badges (first exam, first week, three goals). Exam form correct/incorrect/blank by subject, validated against exam type; calculate and compare net by same exam, distinguish subject aggregates from actual topic evidence.

## Plans
Free: core AI chat, automatic weekly plan, resource advice, progress tracking and motivational features. Daily 3 question photos. Çita+: daily 15, personal error notebook, recurring error analysis grounded in evidence and personalized review sessions. Show one authentic analysis preview from existing learner data then opt-in 14-day auto-renewing trial with platform-displayed terms, price/date, restore and manage. Free core stays usable without payment. Çita Bire Bir monthly includes Plus (same 15 daily), weekly live meetings and between-meeting monitoring; team assigns coach via web admin, then uses existing coach dashboard. Avoid double billing during upgrade. Validate store rules for bundled digital/live services before finalizing real checkout. Implement entitlement logic and sandbox test flows. LGS linked parent can pay for correct student and see weekly plan completion, time and trends; private chats/photos excluded. Secure role linking and minimal exposure.

## Chat, practice, approval
Use approved resource catalog with admin CRUD, metadata (exam/subject/topic/level/type/source URL/last checked); when no suitable item, search public web via server provider and cite result links, mark web source, no fabricated trend claims. Provide practical study advice. Student photo => hint first, then optional full step-by-step solution; both consume one daily allowance, unreadable photos consume zero. Make reset Europe/Istanbul, limits configurable, concurrency-safe and retries idempotent. Private images with authorized access only. Plus notebook saves user-selected question, verified error type (ask learner as needed), and learning context. Find recurring error patterns with evidence; review old question plus two validated similar generated questions, collect independent success/hint usage and propose next review. Include purpose-built structured AI outputs and safe fallback if not enough evidence. Chat never directly writes a plan: show explicit before/after proposal. Free/Plus student approval applies atomically; Bire Bir student approval queues for assigned coach to approve, edit, or decline. Show status and actual applied changes. Preserve old plan until approval and handle stale revisions/retries.
